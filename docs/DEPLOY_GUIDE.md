# 夜自習管理系統　部署與操作指引

> 這份文件寫給「不想研究程式」的人。照著做，兩個階段：先在本機試用，覺得順再上雲端。

---

## 一、資料夾裡有什麼

| 檔案 | 用途 |
|:---|:---|
| `index.html` | 主程式。雙擊就能用，所有操作都在這一頁 |
| `Code.gs` | 雲端後端。只有要「多台電腦共用資料」時才需要 |
| `templates/座位表-範本.docx` | 匯出座位表用的範本（版面與你的原檔相同，表頭的學年度與日期是 `{term}`、`{date}` 標記，匯出時自動填入） |
| `templates/違規單-範本.docx` | 匯出違規通知單用的範本（同上，只有三聯標籤與 `{ }` 標記） |
| `templates/名單範本.xlsx` | 匯出 Excel 用的範本，已清空填寫資料，只留表頭、901 至 908 班級列與總計公式 |
| `templates/座位表-格位.json` | 座位表 51 個格子的位置結構（不含姓名） |

四個範本都不含任何學生姓名、電話或學號，可以安心放在公開的倉庫；資料本體在 Google 試算表。

**重要**：`index.html` 要跟 `templates` 資料夾放在一起，而且要用 GitHub Pages 或本機伺服器開啟（網址是 `http://` 或 `https://`），匯出時才會自動讀到範本。直接用檔案總管雙擊開啟時，瀏覽器會擋住讀取本機檔案，要按一次「選擇範本檔」手動載入。

## 二、階段一：先在本機試用（5 分鐘，不用設定）

1. 用 GitHub Pages 開啟（`https://<你的帳號>.github.io/<專案名>/`），或在專案資料夾執行 `python -m http.server` 後開 `http://localhost:8000`。
2. 上方會顯示「本機模式」，資料存在這台電腦的瀏覽器裡。
3. 切到「匯出表單」分頁，三個範本會自動顯示「已就緒」（就是讀 `templates/` 資料夾裡的那三個檔案）。
4. 按「下載座位表（.docx）」試試看，會得到一份與原檔版面相同、內容由系統產生的座位表。
5. 如果直接用檔案總管雙擊 `index.html`，第 3 步會停在「匯出時自動讀取」，這時按「選擇範本檔」把 `templates` 裡的三個檔案全選，效果一樣。

### 這個時候可以做的事

| 想做的事 | 操作位置 |
|:---|:---|
| 學生改時間 | 指揮台，點該學生一～五其中一格 |
| 登記請假 | 今日看板「未到」名單按「請假」 |
| 點名 | 今日看板「未到」名單按「標記到」 |
| 排座位 | 座位編排分頁，拖曳學生卡到格子 |
| 記錄違規 | 違規紀錄分頁，新增後勾選列印；每列可按「編輯」改學生、日期、點數與事由，下方累積點數表可列印退班通知 |
| 匯出四張表 | 匯出表單分頁 |

### 本機模式的代價

資料只在這台電腦的瀏覽器。**換電腦、換瀏覽器、清除瀏覽資料都會看不到**。
所以試用期間請定期按「備份全部資料（.json）」，並在確定要長期使用時進入階段二。

## 三、階段二：上雲端（約 15 分鐘，做完就一勞永逸）

### 步驟 1　建立 Google 試算表

1. 開啟 <https://sheets.new>
2. 檔名改成「夜自習系統資料庫」（名稱可自訂）
3. 這個試算表就是你的資料庫，不要刪除

### 步驟 2　貼上後端程式

1. 在試算表上方選單點「擴充功能」→「Apps Script」
2. 左側會開一個程式編輯器，把裡面預設的 `function myFunction() {}` 全部刪掉
3. 打開本資料夾的 `Code.gs`，全選複製，貼進編輯器
4. 按 `Ctrl+S` 存檔（名稱可改成「夜自習後端」）
5. 在編輯器上方函式下拉選單選 `初次設定`，按「執行」
6. 第一次會要求授權：選「查看權限」→ 選你的帳號 → 若出現「Google 尚未驗證這個應用程式」點「進階」→「前往（不安全）」
   （這段文字的意思是「這是你自己寫的程式」，不是真的不安全）
7. 執行後會跳出視窗，告訴你工作表已建立、三個範本是否找到

### 步驟 3　範本不必另外上傳

三個範本已經放在專案的 `templates` 資料夾，跟 `index.html` 一起推上 GitHub 就好。前端會用相對路徑 `templates/…` 直接讀取，**不必再上傳到 Google 雲端硬碟**。

只有在「用檔案總管雙擊 `index.html`」又想讓它自動找範本時，才需要上傳到雲端硬碟當備援（檔名不可改）：`座位表-範本.docx`、`違規單-範本.docx`、`名單範本.xlsx`。

### 步驟 4　部署成網頁應用程式

1. 回到 Apps Script 編輯器，右上角按「部署」→「新增部署作業」
2. 左側齒輪圖示選「網頁應用程式」
3. 設定：
   - 說明：`夜自習系統 v1`
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
4. 按「部署」，複製「網頁應用程式」的網址（結尾是 `/exec`）

> 選「任何人」不是把資料公開。真正的門檻是下面那組通關密語，網址被別人拿到也讀不到資料。

### 步驟 5　在試算表設定通關密語（必做）

程式裡沒有寫死任何密語，密語放在試算表：

1. 打開這份試算表，切到「設定」工作表
2. 在最下面新增一列：A 欄填 `password`，B 欄填你自己的密語
3. 存檔就好，不需要重新部署

也可以改成在 Apps Script「專案設定 → 指令碼屬性」新增一筆 `PASSWORD`。兩邊都有時以試算表為準。
之後要換密語，只要改試算表這一列。

### 步驟 6　在網頁填入網址與密語

1. 開啟 `index.html`（或 GitHub Pages 的網址）
2. 畫面上方會出現朱紅提示條「尚未設定雲端」
3. 到「設定與檢查」分頁，貼上部署網址（結尾是 `/exec`）與剛剛設定的密語，按「儲存設定」
4. 提示條消失、右上角變成綠點「雲端模式」，名冊就從試算表讀進來了

網址與密語只存在這台電腦的瀏覽器，程式與倉庫裡都不會有。

之後不管在學校或家裡，開同一個 `index.html` 都是同一份資料。

### 步驟 7　把名冊放進試算表

程式沒有內建名單，第一次使用要有名冊：

1. 在試算表「名單」工作表照表頭填：key（例 901-09）、班級、座號、姓名、電話、便當、一～五（1 或 0）、啟用、學號
2. 若之前用過舊版並按過「備份全部資料」，可以直接到「設定與檢查」按「匯入備份檔」把 JSON 讀回來，系統會整份寫進試算表
3. 回到「今夜點名」確認應到人數正確

> Apps Script 只要改了程式，都必須「新增版本」重新部署，否則線上跑的還是舊版。這是最常見的卡點。

## 四、日常操作

### 學生改參加時間（最常用）

1. 指揮台，找到該學生
2. 點要改的那一格（例如本來上課的「三」）
3. 對話框裡確認新的每週參加日
4. 填「從哪一天開始生效」，預設是基準日
5. 填異動原因，例如「家長來電改為只留一三」
6. 按「儲存異動」

系統會記下這一筆，生效日**之前**的統計與點名不會被改動，之後自動套用。

### 回看過去的點名

點名頁左上可以改日期，回看任何一天。這一頁的名單、一～五方塊、班級人數，全部依「那一天生效的參加設定」呈現：

- 某生 11 月才改成週三不來，10 月的星期三仍會顯示他要來，也仍算在應到名單裡，那天已記錄的點名不會被改寫
- 名字旁若出現朱紅色「異動」小標記，表示他在這天之後又改過設定，滑鼠移上去可看是哪一天改成什麼
- 摘要列下方會列出「之後有異動（N 人，不影響這一天）」，方便核對新舊名單差多少

### 學生請假

1. 切到「請假紀錄」分頁
2. 按「新增請假」，選學生，填起日與迄日（只請一天就兩格填同一天）
3. 填事由，按「建立」

週末與放假日會自動略過，同一天已有紀錄也會跳過；當天若已點「到」會一併取消。
請假只影響當日點名與統計，不會改到每週參加設定。
要取消請假，在列表按「刪除」，或到「今夜點名」點該生今夜的標記（未 → 到 → 假 → 未）。

### 輪值日誌與記事

1. 切到「輪值日誌」分頁：一天一張，第一列是星期、日期、輪值教師與當日人數，下面整條都是記事區
2. 今天固定排在最上面，而且直接就是編輯模式，按「新增一筆記事」就能開始寫；時間會自動帶入當下時刻，可自己改，把時間清空就變成純記事
3. 其他日子預設是瀏覽模式，要補寫或修改時按那張卡片右上的「編輯這天」，改完按「完成」回到瀏覽模式
4. 記事內容直接打字。要指名學生時打 90129（班級加座號），會跳出只含參加學生的選單，點一下就會變成帶底色的班級座號姓名標記，直接嵌在文字裡
5. 打完按勾勾儲存，記事會以整齊樣式呈現；要修改按鉛筆，要刪除按叉叉
6. 已儲存的記事，點裡面的學生標記就能直接建立違規單，事由會自動帶入記事內容

### 退班通知

格式與違規通知單相同，只把「違規」二字改成「退班」，A4 橫式、每份三聯。兩種用法：

- 學生要退出夜自習時，在退出視窗勾選「同時列印退班通知」，退出後直接列印
- 平日要補印，到「違規紀錄」分頁下方的「學生累積點數」表，按該生那一列的「退班通知」

累積點數滿 3 點會標示「達 3 點，依規定退班」。

### 紙本繳回

請假紀錄與違規紀錄各有一欄「已繳紙本」：

1. 通知單發下去後，等學生把紙本繳回
2. 在對應那一列把「已繳紙本」打勾，才算完成
3. 表頭統計（請假頁）與工具列（違規頁）會顯示已繳幾筆，一眼看出還有誰沒交
4. 勾錯了再點一次就取消

### 匯出表單

「匯出表單」分頁有三個按鈕：
| 按鈕 | 產出 | 說明 |
|:---|:---|:---|
| 下載名單總表（.xlsx） | 你的原始 Excel | 總表原地更新數字，另兩張重建為整齊版 |
| 下載座位表（.docx） | A3 橫式座位表 | 版面與原檔相同，51 格自動填入 |
| 列印違規通知單 | A4 橫式 | 違規紀錄分頁按「列印」，直接帶出列印預覽，左右各一份，每份三聯（教學組／導師／家長） |
| 下載違規通知單（.docx） | A4 橫式 | 左右各一份，每份三聯（教學組／導師／家長） |
| 列印退班通知 | A4 橫式 | 從退出視窗或「學生累積點數」表列印，三聯 |

匯出基準日是畫面上方的「基準日」，改它就能產出不同日期的版本。

### 手機上怎麼用

- 點名頁：一位學生一列，第一行是座號與姓名，第二行是五個方塊加上「今夜」狀態，第三行是電話與備註；方塊下方有「今」字的那一天，就是上方選的日期
- 學生清單、請假紀錄、違規紀錄：改成卡片。勾選框在左上，點名字開個人資料，右邊是退出／編輯／刪除；批次工具列多了「全選目前顯示」
- 座位表：格子加寬，姓名不會再變成一字一行，必要時左右滑看完整 14 欄
- 其他頁面（異動日誌、輪值日誌、匯出表單、設定）都是單欄排列，往下捲即可

### 換學期怎麼辦
1. 先按「備份全部資料」保存上學期
2. 到「學生清單」頁，把上學期的參加者勾起來批次「設為不參加」，座位會自動釋出
3. 用班級篩選加勾選，把新學期的學生批次「設為參加」，再按「設定參加日」勾一～五
4. 設定頁把基準日改成新學期的第一天
5. 名冊若有轉入生，直接改 Google 試算表「名單」工作表新增一列，再回設定頁按「從雲端重新載入」

### 這次改版後要做的一件事

這一版把「預設資料」與「寫死的密語」都拿掉了。請做三件事：

1. 到試算表「設定」工作表新增一列：A 欄 `password`、B 欄你的密語
2. 把 `Code.gs` 重新部署一次（部署 → 管理部署 → 編輯 → 版本選新版本 → 部署）
3. 開網頁 →「設定與檢查」填入部署網址與密語 → 按「儲存設定」

之後名冊與所有紀錄都只存在試算表，程式本身與倉庫裡都沒有任何個資。

## 五、常見問題

**Q：匯出時說讀不到範本**
系統會先讀專案內的 `templates/` 相對路徑，所以：
1. GitHub Pages 或本機伺服器（`http://`、`https://`）開啟：確認 `templates` 資料夾有一起推上去，檔名不能改。
2. 用檔案總管雙擊 `index.html`（`file://`）：瀏覽器不准讀本機檔案，請按匯出表單分頁的「選擇範本檔」把三個檔案全選，或改用 GitHub Pages 開啟。
3. 走雲端備援時才會去找雲端硬碟的檔名，請確認三個範本已上傳且檔名完全一致。

**Q：設定頁按儲存後說「雲端連線失敗」**
1. 網址結尾必須是 `/exec`，不是 `/dev`
2. 部署時「具有存取權的使用者」必須選「任何人」
3. 通關密語要與試算表「設定」工作表的 `password` 一列一致（或 Apps Script 指令碼屬性的 `PASSWORD`）
4. 改過程式後要「新增版本」重新部署

**Q：座位表匯出後是空白**
表示座位編排頁還沒有把學生放進格子。按「依班級座號自動排」即可一鍵排滿。

**Q：兩個人同時改會不會互相覆蓋**
會。這版設計給單一使用者（教學組長），每次儲存是整份覆寫。若未來要多人同時編輯，需要改成逐筆寫入的架構。

**Q：可以印出來嗎**
Word 與 Excel 檔都可以直接印。違規通知單與退班通知在頁面上按「列印」就會帶出 A4 橫式的列印預覽；輪值日誌目前用瀏覽器本身的列印功能（Ctrl+P）。

## 六、這版明確做不到的事

| 做不到 | 原因與替代做法 |
|:---|:---|
| 真正的帳號密碼登入 | GAS 沒有會員系統。目前是單一通關密語，只能防誤闖，不能防有心人 |
| 多人同時編輯不衝突 | 採整份覆寫。單人使用沒問題 |
| 即時同步 | 沒有推播機制，換裝置要重新整理頁面 |
| 自動從校務系統抓名單 | 需另行介接 |
| 輪值日誌完全比照紙本格式 | 需你提供紙本樣張才能對版，目前是系統自訂的 A4 表格 |

## 七、出問題時怎麼查

1. 設定頁按「執行自我檢查」，八項全 PASS 表示核心計算正常
2. 瀏覽器按 `F12` 開主控台，看紅字錯誤訊息
3. Apps Script 編輯器左側「執行項目」可看每次呼叫的紀錄與錯誤
4. 資料救援：匯出表單分頁的「備份全部資料（.json）」是完整快照，可用設定頁的「匯入備份檔」還原
