# RDQ 需求規格：輪值教學期管理（修改＋行程＋匯出）

## 一句話任務
讓夜自習系統成為「往後每學期都從這裡處理輪值」的單一入口：可改每日輪值人員、可定起訖時間與放假日原因、並隨時匯出與 `115-1夜自習輪值名單.xlsx` 同版面同套色的 Excel。

## ✅ 已確認
- 輪值修改入口在**輪值日誌頁**：admin 點每天卡片的輪值名字開窗修改；下拉候選取自全學期已出現的人員＋可手打新名字；「**放假**」為彈窗快捷鍵（Ⅲ＋Ⅱ）
- 另製**空白範本**：把 `115-1夜自習輪值名單.xlsx` 清空資料（人名、日期值、標題文字、工作表名都清），**版面、合併、套色、字型、列高、欄寬、細框線、底部四則注意事項全部保留**，放入專案 `templates/`（Ⅰ，夫指示「清空一個 excel 放入範本」）
- 可在系統設定**夜自習開始與結束時間**，匯出用於工作表名與說明文字（Ⅰ，夫口述「要可以定夜自習開始結束時間」）
- 可設定**放假日與原因**：等到既有 `state.calendar`（日期／狀態／說明，後端已同步），admin 在系統內新增／修改／刪除（Ⅰ，夫口述「放假日以及原因」）
- 匯出**同樣版面**的 Excel：學期範圍沿用既有 `夜自習起日（nsStart）／訖日（nsEnd）` 設定（Ⅱ，確認系統已備）；每天卡片依行事曆狀態**套色**（Ⅰ，夫口述「注意套色的部分」）

## 📋 一段式需求規格
在夜自習點名簿（`index.html`）實作「從這裡處理每學期輪值」的三件事。一、輪值修改：輪值日誌頁每天卡片 `dv-head` 的輪值名字（admin）可點，開窗含候選人下拉（取 `state.duty` 全學期 teacher 值去重）、自由輸入與「**放假**」快捷鍵；存檔寫入 `state.duty.teacher` 並走 `commit()` 同步既有「輪值」工作表。二、學期設定：以 `OPTS` 機制新增「輪值開始時間／結束時間」（如 **17:30**、**21:00**，隨設定工作表同步），學期起訖沿用既有 `nsStart／nsEnd`；在輪值日誌頁工具列加「行程／放假日」按鈕，開窗維護 `state.calendar`（**日期、狀態（上課／放假／段考／活動）、說明**，後端「日曆」工作表本就同步）。三、匯出：參考檔 `115-1夜自習輪值名單.xlsx` 清空資料後存為 `templates/輪值表範本.xlsx`（保留 A1 合併標題、15 組「日期／輪值人員」週塊、字型 **Microsoft JhengHei**（標題 20、內文 12 粗體）、日期格式 `m"月"d"日"`、A 欄寬 11.2、細框線置中、底部四則注意事項 A32:F35），匯出時以 **ExcelJS** 載入範本、依照 `nsStart` 起週一到 `nsEnd` 訖週五逐週塊生成：日期列按星期相接（跨週末跳接，同範本公式意涵，填入實(long value 格式 `m"月"d"日"`），表格填色：上課日黃「FFFF00」、放假橘「FF9900」、段考青「00FFFF」、活動綠「00FF00」；輪值人員列付款度放假日填原因標籤、上課日填 `state.duty` 人名（無人名留空）；標題第一行自動組合「**<學期><學校>夜自習留守輪值表<N>天（每人填寫2~3天）**」、N 為學期內非放假日數；工作表命名「**夜自習輪值（<開始>-<結束>）**」（如 1730-2100），說明第 1 條的時間隨設定代入；超過範本行數的週塊用同名複製最後一組取得的樣式延伸。輪值教師身分全程唯讀。
