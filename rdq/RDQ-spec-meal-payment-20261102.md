# RDQ 需求規格：便當費繳交狀態

## 一句話任務
在便當頁為每位訂餐者加上這期便當費的已繳勾選與繳費日期，提供整班一鍵勾選，並把少數忘了繳或月中加入的人集中到頁面上方的未繳通知欄。

## ✅ 已確認
- 每人每期各自一個已繳記號，不是每班一筆。（Ⅲ）
- 勾選時自動記錄繳費日期；退費按已退也記錄退費日期，且要看得見。（Ⅲ）
- 整班繳費用表格上的一鍵全班已繳，不跳確認視窗。（Ⅲ）
- 忘了繳與月中加入的人要出現在最上面的通知欄。（Ⅰ）
- 只有管理員能操作，輪值教師看不到便當頁。（Ⅰ）
- 沿用現有收費期與預繳單金額，不改退費與預繳算法。（Ⅰ）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- 已繳對應預繳單金額，即月初排定份數乘單價加上期折抵，不隨當月請假退費變動；未繳通知顯示的金額用目前實收金額。預設採此定義。
- 應繳 0 或負數的人不列入通知，全班一鍵也不會勾到；月中加入的人不納入全班一鍵，自動留在通知等個別勾。預設採此定義。
- 新的一期預設全部未繳；未繳通知預設展開，開合狀態記在這台裝置。預設採此行為。
- 繳費欄放在表格身份欄右邊，手機卡片另給一顆標記已繳；班級快速鍵放在表格上方，只列班級名稱。預設採此配置。
- 全班一鍵後在提示條提供五秒內復原，避免誤按。預設採此保護。
- 未繳與待退各自獨立，不自動相抵，同一人可能兩邊都出現。預設採此定義。
- 後端新增便當繳費工作表，需重新部署 Code.gs。預設採此做法。

## ❌ 排除項（明確不做）
- 各班收費進度統計（已繳幾人、共幾人）。
- 未繳名單一鍵複製文字貼 LINE。
- 便當預繳單加已繳欄位。
- 繳費操作紀錄（誰在何時勾的）。
- 逾期未繳自動標紅。
- 不改現有退費、預繳與匯出金額算法。

## 📋 一段式需求規格
在夜自習管理系統的便當管理頁，為每個收費期的每位訂餐者增加一個已繳狀態，勾選時自動寫入當天日期，取消勾選即清除。便當格子表格左側身份欄右邊新增繳費欄，已繳顯示勾與月日，未繳顯示空勾框；結算表新增繳費欄，手機卡片提供標記已繳按鈕。表格上方加一排班級快速鍵，點一下就把該班這期應繳大於 0、且不是月中加入、尚未繳費的人全部標成已繳並記當天日期，提示條提供五秒內復原。頁面最上方新增未繳通知欄，列出自動篩出的未繳者，顯示班級座號姓名、應繳金額、身份或加入日，每列有已繳按鈕，可收合且預設展開。退費通知保留，排在未繳通知下方。按已退時記錄退費日期，格子提示與逐日明細顯示退費已退的月日。繳費資料存到新的便當繳費工作表，前端與後端一起更新，部署後舊資料不受影響。

## ✔ 驗收條件
- [x] 按一次 901 全班已繳，班上符合條件者全部顯示已繳與當天日期，月中加入與應繳 0 者不受影響。
- [x] 取消任一人已繳後，上方未繳通知立即出現該人與金額；再按已繳可補回並記錄日期。
- [x] 按已退後，該筆退費記錄當天日期，格子提示與逐日明細看得到。
- [ ] 重新整理或換裝置後，繳費狀態與日期仍在，且舊資料沒有被清掉。（前端與後端程式已完成，待部署 Code.gs 後實機確認）
