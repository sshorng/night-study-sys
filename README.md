# 夜自習管理系統

一份名單，四張表。改一個學生的參加時間，總表、電話表、座位表、違規單一次同步。

- 主程式：`index.html`（單檔，雙擊可用）
- 雲端後端：`Code.gs`（Google Apps Script，選用）

## v5 更新（可調參數集中到試算表「設定」工作表）

- 七個原本寫死在程式裡的設定，全部搬到試算表「設定」工作表，一項一列（A 欄項目、B 欄值）：`school` 學校名稱、`term` 學年度與學期、`vioLimit` 退班點數門檻、`vioReasons` 違規事由清單、`leaveReasons` 請假事由清單、`lunchOptions` 便當選項、`exportPrefix` 匯出檔名前綴
- 「設定與檢查」頁的可調參數區塊由同一份清單自動產生，改完按「儲存設定」就寫回試算表；直接在試算表改、再按「從雲端重新載入」也一樣
- 每項都接到實際畫面：`vioLimit` 決定違規頁「達 N 點，依規定退班」與退班事由的預設文字、`vioReasons` 變成違規視窗的一鍵填入按鈕、`leaveReasons` 與 `lunchOptions` 變成下拉建議、`exportPrefix` 決定下載檔名、`school` 決定通知單表頭與左側標題
- `Code.gs` 只把 `password`、`meta`、`config`、`conflicts`、`updatedAt` 當系統列，其餘每一列都是可調參數，不認識的列會原樣保留
- 這次動到後端，`Code.gs` 要重新部署一次才會雙向同步

## 為什麼要做這個

原本的流程是：學生改了時間，教學組要手動改
1. 總表（每班一～五人數）
2. 參加天數及電話
3. 座位表 Word
4. 違規通知單

同一份事實抄在四個地方，只要漏改一張，數字就對不上。

這套系統把「學生 × 一～五要不要來」變成唯一真相，其餘表單全部由它推算，匯出時以原始檔案為範本填入，版面不會跑掉。

## 三個核心設計

**1. 異動有生效日，不動歷史**

改時間不是覆蓋原檔，而是新增一筆異動紀錄（生效日＋五日勾選＋原因）。
查 9/20 的出席，系統用 9/20 當下有效的設定；查 10/1，用新的設定。過去的統計與點名不會被回算。

**2. 匯出只是填字，不重新排版**

- 座位表：讀你的 `.docx` 範本，只把 51 個儲存格的文字換掉。A3 橫式、1.1 吋欄寬、標楷體、框線全部原封不動。
- 違規單：讀 `.docx` 範本，三聯結構不動，A4 橫式左右各一份，落單的最後一位獨自一頁，不會留下空白表格。
- Excel：讀你的 `.xlsx`，總表在原地寫入新數字，`=SUM()` 公式保留；另兩張重排為整齊版。

**3. 座位是真的在網頁上排**

座位編排頁重現原檔的 51 格結構（3 段，每段 10 個併兩列的高格＋4 欄各兩個矮格），拖曳即可換位，重複入座會即時標紅。

- 真正的帳號驗證（GAS 沒有會員系統，目前只有通關密語）
- 多人同時編輯（採整份覆寫，設計給單人使用）

- 輪值日誌比照紙本格式（需紙本樣張才能對版）

## 檔案結構

```
night-study-sys/（夜自習管理系統）
├── index.html                     主程式（只有介面與邏輯，不含名冊資料）
├── Code.gs                        Google Apps Script 後端
├── docs/DEPLOY_GUIDE.md           部署與操作指引
├── README.md                      本文件
└── templates/
    ├── 座位表-範本.docx            表頭含 {term}、{date}，座位含 {s1}..{s51} 標籤
    ├── 違規單-範本.docx            由原檔轉出，含三聯迴圈標籤
    ├── 名單範本.xlsx               Excel 匯出範本，只留表頭、901 至 908 班級列與總計公式
    └── 座位表-格位.json            51 格位置結構（不含姓名）
```

程式分層：`CONFIG` → `STATE` → `PURE ENGINE` → `API ADAPTER` → `UI VIEW`。
計算邏輯（`E` 物件）零 DOM、零網路請求，所以能被獨立測試，也是上面驗證能跑的原因。
