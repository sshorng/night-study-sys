# 夜自習管理系統

一份名單，四張表。改一個學生的參加時間，總表、電話表、座位表、違規單一次同步。

- 線上版本（GitHub Pages）：https://sshorng.github.io/night-study-sys/
- 主程式：`index.html`（單檔，雙擊可用）
- 雲端後端：`Code.gs`（Google Apps Script，選用）

## v9 更新（修掉「名單總表下載後 Excel 說檔案損毀」，範本十張表全部保留）

- 病因一：`名單範本.xlsx` 是 LibreOffice／Google 那類工具產生的檔，ExcelJS 讀進來再寫出去後，Excel 就判定損毀；連「只讀進來、原封不動寫回去」也一樣，所以問題不在寫入了哪些資料。調代課那類專案之所以轉得過，是因為範本本來就是 Excel 自己存的
- 病因二：範本裡的「重複值」條件格式 ExcelJS 轉不出規則，會留下空的 `<conditionalFormatting/>`，Excel 同樣視為錯誤
- 解法一：範本先用 Excel 自己另存一次，`templates/名單範本.xlsx` 已換成這個版本（內容與格式不變）
- 解法二：轉存後自動清掉空的 `<conditionalFormatting/>`
- 做法：總表把各班五天人數寫成 `COUNTIFS` 公式引用名單，範本的欄寬、框線、字型與合計公式全部沿用；另外新增一張「名單（自動產生）」放全班名單與電話
- 清掉重複：範本那張空白的「參加天數及電話」手寫表與自動名單重複，匯出時直接移除，其餘手寫表保留（匯出檔共 10 張工作表）
- 公式化：名單的「天數」用 `=SUM(E:I)`、每日合計用 `=SUM(...)`、總表五天用 `COUNTIFS`、不參加人數用「總數減參加」，改任何一格都會自己重算；班級總數是名冊人數（含未參加者），維持固定值
- 名單表排整齊：標題列、凍結前兩列、固定欄寬、細框線、每日合計列、A4 橫式縮成一頁寬、每頁重印標題列
- 已用 Excel 實測：10 張工作表、總表合計 54 人與每日 27／27／36／27／27；把名單某一格改成 0 之後，總表與每日合計立刻同步變成 3 與 26，證明公式真的連動

## 為什麼要做這個

原本的流程是：學生改了時間，教學組要手動改
1. 總表（每班一～五人數）
2. 參加天數及電話
3. 座位表 Word
4. 違規通知單

同一份事實抄在四個地方，只要漏改一張，數字就對不上。

這套系統把「學生 × 一～五要不要來」變成唯一真相，其餘表單全部由它推算，匯出時以原始檔案為範本填入，版面不會跑掉。

## 三個核心設計

**1. 異動有生效日，不動歷史**

改時間不是覆蓋原檔，而是新增一筆異動紀錄（生效日＋五日勾選＋原因）。
查 9/20 的出席，系統用 9/20 當下有效的設定；查 10/1，用新的設定。過去的統計與點名不會被回算。

**2. 匯出只是填字，不重新排版**

- 座位表：讀你的 `.docx` 範本，只把 51 個儲存格的文字換掉。A3 橫式、1.1 吋欄寬、標楷體、框線全部原封不動。
- 違規單：讀 `.docx` 範本，三聯結構不動，A4 橫式左右各一份，落單的最後一位獨自一頁，不會留下空白表格。
- Excel：讀你的 `.xlsx`，總表在原地寫入新數字，`=SUM()` 公式保留；另兩張重排為整齊版。

**3. 座位是真的在網頁上排**

座位編排頁重現原檔的 51 格結構（3 段，每段 10 個併兩列的高格＋4 欄各兩個矮格），拖曳即可換位，重複入座會即時標紅。

## 檔案結構

```
night-study-sys/（夜自習管理系統）
├── index.html                     主程式（只有介面與邏輯，不含名冊資料）
├── Code.gs                        Google Apps Script 後端
├── docs/DEPLOY_GUIDE.md           部署與操作指引
├── README.md                      本文件
└── templates/
    ├── 座位表-範本.docx            表頭含 {term}、{date}，座位含 {s1}..{s51} 標籤
    ├── 違規單-範本.docx            由原檔轉出，含三聯迴圈標籤

    └── 座位表-格位.json            51 格位置結構（不含姓名）
```

程式分層：`CONFIG` → `STATE` → `PURE ENGINE` → `API ADAPTER` → `UI VIEW`。
計算邏輯（`E` 物件）零 DOM、零網路請求，所以能被獨立測試，也是上面驗證能跑的原因。
